## 📄 How to Print to PDF

### Chrome / Edge

1. Open the HTML file in the browser
2. Press `Ctrl + P` (Windows) or `Cmd + P` (Mac)
3. Change "Destination" to **"Save as PDF"**
4. Set Paper size to **Letter**
5. Set Margins to **None** or **Minimum**
6. Enable **"Background graphics"** checkbox
7. Click **Save**

### Firefox

1. Open the HTML file in the browser
2. Press `Ctrl + P` (Windows) or `Cmd + P` (Mac)
3. Select **"Save to PDF"** as printer
4. Set Paper size to **Letter**
5. Click **Print**

### Safari (Mac)

1. Open the HTML file in Safari
2. Press `Cmd + P`
3. Click the **PDF** dropdown in the bottom left
4. Select **"Save as PDF"**
